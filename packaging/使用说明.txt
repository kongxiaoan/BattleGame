BattleGame 使用说明

1. 根据电脑类型选择压缩包：
   - Apple Silicon：M1、M2、M3、M4 等芯片使用 arm64 版。
   - Intel：使用 x64 版。

2. 解压 ZIP 后，双击“开始游戏.command”。

3. 如果 macOS 提示无法验证开发者：
   - 在“系统设置 → 隐私与安全性”中找到拦截提示。
   - 确认文件来自可信朋友后，选择“仍要打开”。

4. 如果仍无法启动，可打开“终端”，进入解压目录后执行：
   chmod +x BattleGame 开始游戏.command
   xattr -d com.apple.quarantine BattleGame 开始游戏.command
   ./BattleGame

游戏已经包含 .NET 运行时，无需另外安装 .NET。

局域网双人对战

1. 由一名玩家双击“启动局域网服务器.command”。
2. 服务窗口会显示这台 Mac 的局域网 IP，请保持窗口开启。
3. 两名玩家分别双击“开始游戏.command”：
   - 房主选择“局域网 · 创建好友房”，服务器地址使用默认 127.0.0.1。
   - 另一名玩家选择“局域网 · 加入好友房”，输入房主服务窗口显示的 IP。
4. 输入同一个 6 位房间码后即可开始。

切换公网服务端

- 客户端和局域网服务器使用同一套 WebSocket 协议。
- 编辑同目录的“在线服务器地址.txt”，填入 wss:// 地址后，主菜单可一键切换。
- 也可以使用环境变量临时覆盖文件配置：
  export BATTLEGAME_SERVER_URL="wss://你的域名/ws"
- 切换地址不需要重新构建客户端。

DeepSeek AI（可选）

- 不配置 API Key 也可以完整游玩，游戏会使用本地电脑策略和本地裁判。
- 单机模式可继续读取玩家自己的 Key。
- 联网模式的 DeepSeek Key 必须只配置在服务端，不能下发到玩家客户端。
- 在终端进入解压目录后运行：
  export DEEPSEEK_API_KEY="你的 Key"
  export DEEPSEEK_MODEL="deepseek-chat"
  ./BattleGameServer
- 双击启动脚本时如需带 Key，可先在终端导出环境变量，再执行“启动局域网服务器.command”。
